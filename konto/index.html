Firmen

Für Buchhalter und Treuhänder: Legen Sie für jede Firma, die Sie betreuen, eine eigene Buchhaltung an. Sie wechseln mit einem Klick, ohne neues Passwort. Die Daten jeder Firma bleiben strikt getrennt.

Ihrem Buchhalter Zugang geben

Ihr Buchhalter oder Treuhänder kann dann in dieser Firma alles bearbeiten, wie Sie selbst. Er braucht dafür ein Ordasio-Konto (gratis). Sie können den Zugang jederzeit wieder entziehen.
